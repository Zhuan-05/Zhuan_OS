# Handoff Protocol

Use this when transferring work between ChatGPT, Codex, Claude Code, Marvis, or Zhuan.

## Handoff Format

### Task

What is the exact task?

### Current State

What is true now?

### What Was Done

What actions were completed?

### What Was Not Done

What is intentionally unfinished?

### Files Touched

List files or route-level paths only. Do not reveal private filenames.

### Git Status

Summarize `git status --short`.

### Risk

What can go wrong next?

### Next Action

One smallest safe next action.

## Rule

Never hand off vague intent. Hand off state, evidence, risk, and next action.
