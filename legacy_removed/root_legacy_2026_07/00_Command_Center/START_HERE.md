# Start Here

Zhuan_OS is Zhuan's AI Thinking and Execution Operating System.

Use it for active work: thinking, planning, prompts, agents, workflows, logs, reviews, and execution context.

Storage split:

- `D:\Zhuan_OS` = operating system and active AI workflow layer.
- `D:\Zhuan_Vault` = storage and knowledge vault.
- `D:\Zhuan_Vault\01_Private` = Zhuan_Private_Vault, private storage only.

## Daily Route

1. Check `TODAY.md`.
2. Pick one task.
3. Choose AI mode.
4. Execute.
5. Review.

## Rule

Do not use the Vault as the active OS. Do not use the OS as long-term file storage.
