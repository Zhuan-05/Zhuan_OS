# Codex Workflow

## Standard Loop

1. Read the request.
2. Inspect the repo.
3. Identify risk.
4. Make the smallest useful change.
5. Verify with tests, Git status, or targeted checks.
6. Report outcome and next action.

## Use Codex For

- Repository edits.
- Git safety checks.
- Refactors with verification.
- Documentation updates.
- Local automation.

## Avoid

- Broad rewrites without approval.
- Secret inspection.
- Destructive commands without explicit confirmation.
