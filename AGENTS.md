# AGENTS.md

## Zhuan OS Rules

- Read `_Context/` first when a task depends on active operating context.
- Preserve useful existing files.
- Do not delete files without explicit confirmation.
- Do not touch `D:\Zhuan_Vault`.
- Do not modify Obsidian vault files unless explicitly asked.
- Do not touch secrets, tokens, API keys, credentials, or production data.
- Prefer small, reversible changes.
- Log meaningful framework changes in `_Agent/CHANGELOG.md`.

## Where to Look

- `docs/` for repo-level policy and setup notes.
- `prompts/` for reusable Codex and Claude Code prompts.
- `logs/` for decision, task, and risk tracking.
