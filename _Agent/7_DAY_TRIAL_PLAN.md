# 7 Day Trial Plan

## Purpose

Test whether `D:\Zhuan_OS` works as a practical Active AI Knowledge Operating System before expanding it.

## Day 1

- Open the vault in Obsidian.
- Capture only new active thoughts in `00_Inbox/Mobile Capture.md`.
- Do not migrate old files.

## Day 2

- Create one daily note.
- Create one learning note from current coursework.

## Day 3

- Create one project note for an active project.
- Add next actions and risks.

## Day 4

- Record one decision in `05_Decision/Decision Log.md`.
- Add one principle if useful.

## Day 5

- Use NotebookLM for one raw source.
- Write only distilled understanding into Obsidian.

## Day 6

- Review whether folder routing feels clear.
- Adjust only if there is repeated friction.

## Day 7

- Complete a weekly review.
- Decide whether to initialize lightweight GitHub backup later.

## Success Criteria

- Capture is fast.
- Active context is easy to find.
- AI Agent boundaries are clear.
- No raw file dumping.
- No old vault dependency for daily work.
