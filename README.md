# Zhuan_OS

`D:\Zhuan_OS` is the active AI Knowledge Operating System.

It is designed for daily capture, active learning, project execution, decision-making, review, Context Engineering, AI Agent workflows, and continuous self-updating.

`D:\Zhuan_Vault` is the old archive/raw database. It is treated as a Cold Archive / Raw Database / Historical Vault, not the active daily system.

## Core Loop

Capture -> Understand -> Organize -> Decide -> Act -> Review -> Improve

## Operating Principle

This vault is not a storage dump. It should contain active knowledge, distilled understanding, current project context, decisions, reviews, and lightweight references.

Raw files, large files, sensitive files, and old historical material should stay in Google Drive / OneDrive, the old vault, or other appropriate storage.
