# System Context

## Purpose

`D:\Zhuan_OS` is the active AI Knowledge Operating System for Zhuan's daily capture, active learning, project execution, decision-making, review, Context Engineering, and AI Agent workflows.

## Main Goal

Build a lightweight, sustainable, self-updating knowledge system that helps Zhuan think clearly, learn actively, make better decisions, and coordinate AI tools safely.

## System Philosophy

This vault stores active knowledge and distilled understanding, not raw dumps. It should keep context clear, current, and usable by both Zhuan and AI Agents.

## Tool Roles

- Obsidian: active knowledge system.
- GitHub: lightweight backup and version control.
- NotebookLM: learning teacher for raw study files.
- Google Drive / OneDrive: raw file storage.
- Notion: action dashboard.
- Codex / Claude Code: maintenance agents.
- Old `D:\Zhuan_Vault`: archive/database only.

## Core Loop

Capture -> Understand -> Organize -> Decide -> Act -> Review -> Improve

## AI Context Rule

AI Agents must read `_Context` first before scanning folders. Do not scan the old vault or private folders by default.
