# Tool Roles

## Obsidian

The active knowledge system for notes, learning, project context, decisions, reviews, and AI workflow context.

## GitHub

Lightweight backup and version control. Track mostly Markdown and safe configuration files.

## NotebookLM

Learning teacher for raw study sources. Use it to explain, quiz, compare, and extract understanding from large learning materials.

## Google Drive / OneDrive

Raw file storage for large PDFs, PPTX, DOCX, videos, scans, and historical material.

## Notion

Action dashboard for tasks, timelines, high-level project management, and structured operational views.

## Codex

Maintenance and engineering agent for structure, scripts, documentation, automation, and code-related workflows.

## Claude Code

Coding and long-context engineering assistant for project implementation, refactoring, and codebase understanding.

## Mobile Phone

Fast capture, quick review, lightweight note entry, and daily check-ins.
