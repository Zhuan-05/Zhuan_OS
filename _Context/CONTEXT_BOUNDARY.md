# Context Boundary

## Restricted Content

- passwords
- API keys
- tokens
- SSH private keys
- bank login details
- identity scans
- sensitive family/private documents
- raw large files
- `.env` files
- old workspace/cache files

## Restricted Folders

- `D:\Zhuan_Vault` private folders
- any folder named `Private`
- any folder named `Secrets`
- any folder named `Money`
- any folder named `Personal`
- any folder named `Journal`

## Context Minimization Rule

Use summaries, Context Maps, and active files first. Only inspect raw files when explicitly needed.
